# Rooh Eval OMS v2.0

نظام إدارة الطلبات الاحترافي

## المميزات

- **إدارة المنتجات**: إضافة، تعديل، حذف المنتجات مع رفع الصور
- **إدارة الفواتير**: إنشاء فواتير ببيانات العميل الكاملة مع إمكانية الطباعة
- **لوحة تحكم**: إحصائيات ورسوم بيانية تفاعلية
- **تصميم فخم**: واجهة داكنة بألوان ذهبية احترافية
- **دعم RTL**: دعم كامل للغة العربية
- **تخزين محلي**: حفظ البيانات في localStorage

## التقنيات المستخدمة

- **Frontend**: Next.js 14, React 18, TypeScript
- **التصميم**: Tailwind CSS, Framer Motion
- **الرسوم البيانية**: Recharts
- **الأيقونات**: React Icons

## التشغيل

```bash
# تثبيت المكتبات
npm install

# تشغيل في وضع التطوير
npm run dev

# بناء للإنتاج
npm run build

# تشغيل الإنتاج
npm start
```

## بيانات الدخول التجريبية

- **اسم المستخدم**: admin
- **كلمة المرور**: admin123

## الصفحات

| الصفحة | المسار | الوصف |
|--------|--------|-------|
| لوحة التحكم | `/` | إحصائيات ورسوم بيانية |
| المنتجات | `/products` | إدارة المنتجات مع رفع الصور |
| الفواتير | `/invoices` | إنشاء وعرض وطباعة الفواتير |
| الإعدادات | `/settings` | إعدادات النظام والملف الشخصي |
| تسجيل الدخول | `/login` | صفحة تسجيل الدخول |
| الترحيب | `/welcome` | شاشة الترحيب |
| 404 | أي مسار خاطئ | صفحة الخطأ |
