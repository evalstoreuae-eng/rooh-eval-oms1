## لوحة التحكم وإدارة الموظفين والشركاء

- تمت إضافة صفحة تجريبية إدارية على المسار `/admin` تسمح بإضافة/تعديل/حذف الموظفين والشركاء وتحديد نسب الأرباح.
- تحتوي اللوحة على نموذج فواتير تجريبي مع حقول: رقم يدوي، عميل، إمارة، منطقة، مبلغ، عملة.

## التخزين السحابي والمحلي

- تحفظ الفواتير والبيانات ذات الصلة فوراً على LocalStorage محلياً (مفتاح: `rooh:invoices`, `rooh:employees`, `rooh:partners`).
- تمت إضافة تجهيز لربط Supabase في `src/lib/supabase.ts` — إذا قمت بضبط المتغيرات البيئية `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` سيتم محاولة مزامنة الجداول `invoices`, `employees`, `partners` تلقائياً (تفترض وجود هذه الجداول في Supabase).

## PWA وملفات التثبيت

- تمت إضافة `public/manifest.json` وملفات أيقونات تجريبية في `public/icons/` وكذلك Service Worker في `public/sw.js`.
- تم تسجيل Service Worker في `src/pages/_app.tsx` وإضافة Meta tags وملف الوثيقة في `src/pages/_document.tsx` لدعم التثبيت على الشاشة الرئيسية.

## تشغيل المشروع

نفس أوامر التشغيل المعتادة:

```bash
npm install
npm run dev
```

ملاحظات هامة:
- التعديلات المقدمة تجريبية وتهدف لتوفير أساس سريع للتطوير. تحتاج إلى:
  - إنشاء جداول Supabase (`invoices`, `employees`, `partners`) إذا رغبت بالمزامنة.
  - إضافة أيقونات PNG حقيقية بدلاً من SVG إن رغبت بالدعم الكامل عبر كل المتصفحات.
  - دمج تحقّق صلاحيات المستخدم الحقيقية (auth) قبل منح صلاحيات إدارة.
